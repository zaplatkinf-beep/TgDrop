# TgDrop

Локальный помощник для Windows 10 и Telegram Desktop: перетаскивание файлов, фото и текста из чата в открытую папку Проводника.

## Скачать и запустить

Скачай готовый **[TgDrop.exe из последнего релиза](https://github.com/zaplatkinf-beep/TgDrop/releases/latest/download/TgDrop.exe)** и запусти его. Устанавливать инструменты разработки и собирать исходники не нужно. Нужен .NET Framework 4.x, встроенный в Windows 10.

Утилита работает локально, без входа в Telegram и без отправки данных на сервер. Её можно свернуть в трей. Для запуска сразу в трее используй `TgDrop.exe --tray`.

## Использование

1. Запусти `TgDrop.exe`. Галочка «Включить перетаскивание» должна быть включена.
2. Открой папку назначения в Проводнике и расположи её рядом с Telegram.
3. Дождись полной загрузки фото. Если видна только миниатюра, открой фото, дождись загрузки и вернись в чат.
4. Зажми левую кнопку на фото в чате и тяни в область файлов открытой папки.
5. Когда область станет синей, отпусти кнопку. Фотография появится в текущей открытой папке.

Для текста: выдели нужный фрагмент в Telegram, затем зажми левую кнопку внутри выделения и перетащи его в область файлов открытой папки. При отпускании появится `.txt` в UTF-8 с BOM, чтобы Блокнот Windows правильно распознавал кириллицу. Переносы строк, пробелы и эмодзи сохраняются как их передал Telegram. Каждое перетаскивание создаёт отдельный файл с уникальным именем.

Для обычных файлов: сначала скачай вложение в Telegram, затем перетащи его в область файлов открытой папки. Поддерживаются любые расширения: PDF, DOCX, ZIP, видео и другие. Создаётся копия с исходным именем. Если имя занято, добавляется номер: `Документ (1).pdf`. Существующие файлы не заменяются, исходник не удаляется. Большие файлы копируются потоком без загрузки целиком в память. Во время копирования большого файла окно может временно не отвечать. Папки не копируются.

Область приёма относится ко всей текущей папке. Если нужна вложенная папка, сначала открой её. Перетаскивание на значок закрытой папки или на рабочий стол пока не поддерживается. Перетаскивай по одному файлу или фото.

Окно можно свернуть в трей кнопкой. Двойной щелчок по значку открывает окно. «Выход» в меню значка полностью останавливает помощник. Автозапуск не добавляется.

## Как это работает

Telegram Desktop передаёт при перетаскивании загруженной фотографии изображение и, при наличии, исходные JPEG-байты (`image/jpeg`). Проводник ожидает файловый объект. TgDrop показывает временную область приёма над файловой областью Проводника, принимает данные изображения и записывает файл в открытую папку. Путь определяется через Windows Shell.

При наличии JPEG-данных они сохраняются без перекодирования. Если Telegram передал только bitmap, сохраняется PNG. Имена уникальны; существующие файлы не заменяются. Исходный файл не удаляется. Утилита не использует сеть, не читает переписку, не меняет буфер обмена и не требует входа в аккаунт. Защищённые от копирования и ещё не загруженные фотографии Telegram может не отдавать.

Предназначено для обычных файловых папок Проводника Windows 10. Виртуальные разделы вроде «Этот компьютер» не являются папкой назначения. Работа с вкладками Windows 11 не проверена.

## Сборка и проверки

Исходник: `src/TgDrop.cs`. Сборка: `powershell -ExecutionPolicy Bypass -File .\build.ps1`. Используется встроенный компилятор .NET Framework; установка дополнительных пакетов не нужна.

`TgDrop.exe --self-test` проверяет сохранение исходных JPEG и PNG, преобразование bitmap, уникальные имена, копирование файла с сохранением источника, сохранение текста с кириллицей, эмодзи, переносами строк и пробелами, UTF-8 BOM, приоритет изображения над подписью и отклонение неподдерживаемых данных. Результат записывается в `self-test-result.txt`.

Проверки обычных файлов включают PDF, ZIP, EXE, имена на кириллице, файлы без расширения и пустые файлы, сохранение исходных байтов, нумерацию при совпадении имён, копирование в ту же папку, сохранность источника и приоритет вложения над его миниатюрой и подписью.

`TgDrop.exe --diagnose` проверяет обнаружение открытой папки Проводника и пишет `diagnostics.txt`.

Для ручной проверки OLE без личных фото: запусти помощник с `--test-source` и второй экземпляр с `--drag-test-source`, затем перетащи синее тестовое фото в открытую папку. Тестовый источник передаёт JPEG и bitmap без пути к файлу, аналогично Telegram. Закрой тестовые экземпляры и запусти обычный режим.

Автоматическая проверка сохранения не заменяет проверку живого перетаскивания из Telegram.
